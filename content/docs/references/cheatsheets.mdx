Cheat sheets should shorten recall time without replacing understanding. Verify every command against the current challenge and authorized scope.

## Files and encodings

```bash
file artifact
xxd -g 1 artifact | head
strings -a -n 6 artifact | less
base64 -d input.txt > output.bin
```

## Network capture

```bash
tshark -r capture.pcapng -q -z io,phs
tshark -r capture.pcapng -Y 'http.request' -T fields -e http.host -e http.request.uri
tcpdump -nn -r capture.pcap 'tcp port 80'
```

## ELF triage

```bash
file ./challenge
checksec --file=./challenge
readelf -h -l -S -s ./challenge
objdump -d -M intel ./challenge | less
```

## Web requests

```bash
curl -i --http1.1 https://target.example/
curl -sS -D headers.txt -o body.bin https://target.example/resource
```

## Hashes

```bash
sha256sum artifact
find evidence -type f -print0 | sort -z | xargs -0 sha256sum
```

Add a command only when its flags are understood and its output has been validated on the team baseline environment.
