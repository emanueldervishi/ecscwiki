Welcome to the working knowledge base for **ECSC Albania**. This wiki exists to make every training session, challenge solve, and competition lesson useful to the whole team.

## Start with the team handbook

New members should complete [Start here](/docs/onboarding/start-here), read the [code of conduct](/docs/onboarding/code-of-conduct), and prepare an isolated environment through the [lab access guide](/docs/infrastructure/lab-access).

## Choose a primary track

| Track | Focus | First milestone |
| --- | --- | --- |
| [Binary exploitation](/docs/training/pwn) | Memory corruption and exploit development | Triage and solve a protected 64-bit binary |
| [Web security](/docs/training/web) | Application logic and server-side vulnerabilities | Build a complete request and trust-boundary map |
| [Reverse engineering](/docs/training/reverse-engineering) | Static and dynamic program analysis | Recover the verification logic from a stripped binary |
| [Cryptography](/docs/training/cryptography) | Applied mathematics and implementation failures | Identify the primitive and test its assumptions |
| [Forensics](/docs/training/forensics) | Disk, memory, network, and metadata analysis | Preserve evidence and produce a defensible timeline |

## Operate as a team

Technical ability matters, but coordination converts ability into points. Before an event, review the [competition-day playbook](/docs/operations/competition-day). During an event, follow the [communication protocol](/docs/operations/communication). After a solve, use the [write-up standard](/docs/operations/writeup-standard).

> Do not store live flags, credentials, private keys, personal data, or embargoed challenge material in the wiki.

## Contribution principle

Write for the teammate who will face a similar problem six months from now. Record the environment, commands, evidence, assumptions, dead ends, final reasoning, and transferable lesson.
