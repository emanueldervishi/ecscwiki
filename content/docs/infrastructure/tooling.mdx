Install tools inside the isolated lab environment and record versions in every reproducible write-up.

## Shared baseline

```bash
sudo apt update
sudo apt install -y git curl jq tmux build-essential python3 python3-venv
```

Prefer virtual environments, containers, or dedicated package managers over installing challenge-specific Python packages globally.

## Category sets

| Track | Baseline tools |
| --- | --- |
| Binary exploitation | GDB, pwndbg, pwntools, ROPgadget, one_gadget |
| Web security | Burp Suite, mitmproxy, curl, httpie, ffuf |
| Reverse engineering | Ghidra, GDB, radare2, strace, ltrace |
| Cryptography | Python, SageMath, PyCryptodome, z3 |
| Forensics | Wireshark, Volatility 3, Sleuth Kit, ExifTool, binwalk |

## Version capture

```bash
python3 --version
gdb --version | head -n 1
git rev-parse HEAD
```

If a solve depends on a container image, pin the digest. If it depends on a repository, record the commit SHA rather than only the branch name.

## Secrets

Never place VPN credentials, API tokens, SSH private keys, session cookies, or flags in shell history, source files, screenshots, or the wiki.
